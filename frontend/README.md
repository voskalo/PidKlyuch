# PidKlyuch Frontend

Веб-інтерфейс калькулятора розмитнення «Під ключ» (React 19 + TypeScript + Vite + Tailwind CSS v4 + Lucide Icons).

## Можливості

- 📦 **Калькулятор посилок:** вибір категорії, валюти (EUR, USD, UAH, PLN, GBP), фактурної вартості та доставки.
- 🚗 **Калькулятор автомобілів:** підтримка бензинових, дизельних, гібридних та електричних авто з динамічними полями (об'єм ДВЗ vs ємність батареї), розрахунком коефіцієнта віку $K_{age}$ та перевіркою походження з ЄС (сертифікат EUR.1 — 0% мита).
- ⚖️ **Порівняння правил:** швидке порівняння «Зараз vs Липень 2027» (Закон 5025-IX щодо скасування порогу €150 для ПДВ).
- 📊 **Прозорі формули:** детальний розклад кожного податкового платежу (мито, акциз, ПДВ) з математичною формулою розрахунку.
- 💱 **Курси валют:** віджет офіційного курсу НБУ з індикатором джерела (live / fallback) та датою.
- 👤 **Автентифікація:** реєстрація, вхід, сесія через JWT Bearer токен.
- 📜 **Історія розрахунків:** автоматичне збереження розрахунків для авторизованих користувачів, перегляд деталей та видалення.
- 💛💙 **Кнопка донату на ЗСУ:** посилання на «Повернись живим», Фонд Сергія Притули та банку Monobank для виконання бонусного критерію оцінювання.
- 📈 **Метрики використання:** модальне вікно для перегляду лічильників з `/api/stats`.

## Як запустити локально

### 1. Встановити залежності

```bash
cd frontend
npm install
```

### 2. Запуск у режимі розробки

```bash
npm run dev
```

За замовчуванням інтерфейс відкривається на `http://localhost:5173`.
Запити до `/api/*` автоматично проксуються на бекенд `http://127.0.0.1:8000`.

### 3. Збірка для продакшну

```bash
npm run build
```

Статичні оптимізовані файли створюються у папці `frontend/dist/`.
Для деплою на AWS S3 + CloudFront або AWS Amplify достатньо завантажити вміст `frontend/dist`.

### Змінні оточення (опціонально)

Створіть `.env` у папці `frontend/`:

```env
# Якщо бекенд знаходиться на іншому хості/домені:
VITE_API_BASE_URL=https://api.yourdomain.com
```
Якщо змінна не задана, запити йдуть на відносний шлях `/api` (що ідеально для CloudFront з одним доменом або для Vite dev proxy).
